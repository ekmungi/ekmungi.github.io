## The problem

In a context-aware operating room, systems use data from the procedure to recognise surgical activities, so that they can support the team. Surgeons, in turn, need standardised feedback on their performance.

Researchers who work on surgical instrument detection also need shared benchmark data and consistent labels, so that their methods can be compared.

## What was done

With clinicians I researched the detection and analysis of surgical workflow, using intra-operative data that I collected: video, device annotations, procedure phases and operating-room workflow. Machine learning recognised the phases of each procedure and measured how long each surgeon spent in each phase.

With the same data I examined whether complications were linked to the length of the procedure or to the instruments used, and I analysed training videos for surgeon skill assessment.

I raised the sponsorship for the Endoscopic Vision (EndoVis) challenges at MICCAI 2017 and 2018 and helped organise them. I also worked on label standardisation for surgical instrument detection, to make the methods comparable.
