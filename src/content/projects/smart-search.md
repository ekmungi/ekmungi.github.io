Smart Search runs entirely on my own computer. It reads PDF, Word, PowerPoint, Excel, HTML and Markdown files, from an Obsidian vault or from any folder of documents, and searches them by meaning and by keyword together.

Claude Code and other AI agents reach it through an MCP server, so they can find a passage and cite where it came from. It also offers a REST interface and a desktop app.
